# Kuchařky DDDA

Kuchařka je opakovatelný pracovní postup. Každá obsahuje účel, předpoklady, chat prompt, technické kroky, Miro změny, výstupy, kontroly, chyby a navazující gate. Kuchařky nepředstavují lineární waterfall; podle nové evidence se lze vracet.

Doporučené pořadí pro nový projekt: 01 → 02 → 03 → 04 → 06 → 08, poté podle vybraného bounded contextu 05 a implementační kroky.
