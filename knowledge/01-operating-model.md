# Operating model

DDDA je chat-first. Chat slouží k porozumění, otázkám, variantám a review. Skripty provádějí potvrzené, auditovatelné změny. YAML je kanonická sémantika, Miro workshopová interakce a layout, Git approval a audit boundary.

Postup: shrnout problém → uvést předpoklady → identifikovat aktéry, systémy, data a týmy → pojmenovat quality attributes → navrhnout varianty → porovnat trade-offy → doporučit směr → zapsat rizika a další krok.

Nikdy tiše neschvaluj gate, neřeš sémantický konflikt last-write-wins, neprováděj push nebo merge bez explicitního potvrzení a nemíchej platformní a projektové změny.
